# Ścieżki użytkowników

## Pierwsza publikacja

Rejestracja → organizacja → branża → szablon → przegląd pytań → ustawienie obszaru/budżetu → test → publikacja → wybór instalacji → testowy lead → checklista gotowości.

Punkty ryzyka: zbyt wiele decyzji na starcie, niezrozumiałe reguły i publikacja bez testu. System zapisuje postęp, pozwala pominąć branding i blokuje publikację tylko przy błędzie krytycznym.

## Klient końcowy

Wejście ze strony → informacja o czasie i prywatności → pytania kwalifikacyjne → zakres → budżet i termin → pliki opcjonalne → kontakt i zgody → wynik → potwierdzenie e-mail.

Proces zachowuje lokalny identyfikator sesji, nie wymaga konta, pokazuje postęp jako zakres, nie obiecuje dokładnej liczby kroków przy rozgałęzieniach i umożliwia „nie wiem”.

## Obsługa leada

Powiadomienie → szczegóły leada → przyczyny score → szybki kontakt → status → notatka/następny krok → historia. Brak kontaktu po ustalonym czasie pojawia się w „Wymaga uwagi”.

## Agencja

Utworzenie klienta → sklonowanie szablonu → branding → konfiguracja → test z klientem → publikacja → instalacja WordPress → przekazanie uprawnień → monitoring.
