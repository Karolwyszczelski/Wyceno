# Architektura informacji

## Panel

- Start: dashboard i „Wymaga uwagi”;
- Leady: lista → szczegóły;
- Procesy: lista → builder → test → publikacja → instalacja;
- Szablony;
- Analityka;
- Integracje;
- Ustawienia: organizacja, zespół, branding, prywatność, API/audit;
- Agencja: klienci i przełącznik organizacji, gdy model zostanie aktywowany.

## Builder desktop

Lista kroków | rzeczywisty podgląd/edycja | ustawienia kontekstowe. Górny pasek: nazwa, status, zapis, undo/redo, podgląd, publikacja. Nie stosujemy swobodnego canvasu ani grafu node-based w MVP.

## Lead details

Nagłówek z kontaktem, statusem, score i ceną; główna kolumna z podsumowaniem, odpowiedziami, plikami, historią i zgodami; panel operacyjny z opiekunem, następnym krokiem, notatką i źródłem.
