# Jobs To Be Done

## Firma usługowa

- Gdy otrzymuję wiele ogólnych zapytań, chcę zebrać minimalny komplet danych przed rozmową, abym mógł szybko ocenić dopasowanie.
- Gdy klient pyta o cenę, chcę pokazać bezpieczny przedział i jego założenia, abym nie tworzył wiążącej obietnicy.
- Gdy pojawia się nowy lead, chcę zrozumieć jego priorytet i przyczyny, abym reagował we właściwej kolejności.
- Gdy zmienia się oferta, chcę poprawić pytania i reguły bez programisty, nie zmieniając historycznych leadów.

## Agencja

- Gdy wdrażam kolejnego klienta, chcę sklonować sprawdzony proces i dostosować branding, aby ograniczyć koszt wdrożenia.
- Gdy zarządzam wieloma klientami, chcę twardej separacji danych i prostego WordPress connectora, aby ograniczyć ryzyko operacyjne.

## Klient końcowy

- Gdy nie wiem, ile usługa kosztuje, chcę odpowiedzieć na zrozumiałe pytania i otrzymać orientację, aby zdecydować o kontakcie.
- Gdy nie znam odpowiedzi technicznej, chcę móc zaznaczyć „nie wiem”, aby nie porzucać procesu ani nie zgadywać.
