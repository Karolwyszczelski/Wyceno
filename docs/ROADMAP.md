# Roadmap

Roadmap jest sekwencją ryzyka, nie obietnicą dat. Etap zaczyna się dopiero po gate poprzedniego.

| Etap                   | Status                       | Wynik                                          | Gate                        |
| ---------------------- | ---------------------------- | ---------------------------------------------- | --------------------------- |
| 0 Discovery            | ukończony dokumentacyjnie    | spójny problem, zakres, architektura i backlog | review dokumentacji         |
| 1 Fundament            | lokalnie zielony; CI czeka   | monorepo, tooling, strict TS, test, CI, env    | lint/typecheck/test/build   |
| 2 Design foundation    | lokalnie ukończony; CI czeka | tokeny, bazowe komponenty i layout             | visual + keyboard review    |
| 3 Baza i auth          | nierozpoczęty                | schema, migracje, org, role, RLS               | test tenant isolation       |
| 4 Flow domain          | nierozpoczęty                | draft, wersje, publikacja, szablony            | publikowalny proces         |
| 5 Widget               | nierozpoczęty                | renderer, sesja, odpowiedzi, warunki           | proces bez ceny             |
| 6 Pricing/scoring      | nierozpoczęty                | deterministyczne silniki                       | edge cases + explainability |
| 7 Lead pipeline        | nierozpoczęty                | kontakt, lead, pliki, status, historia         | pełna ścieżka               |
| 8 Powiadomienia        | nierozpoczęty                | e-mail i delivery logs                         | test HTML/text/delivery     |
| 9 Analityka            | nierozpoczęty                | eventy, agregacje, dashboard                   | zgodność metryk             |
| 10 Landing/SEO         | nierozpoczęty                | marketing, branże, techniczne SEO              | crawl/CWV review            |
| 11 WordPress           | nierozpoczęty                | connector, shortcode, blok, popup              | testy WP                    |
| 12 Security/compliance | nierozpoczęty                | audyt, retencja, eksport/usuwanie              | brak krytycznych ustaleń    |
| 13 Produkcja           | nierozpoczęty                | staging, backup, monitoring, rollback          | release checklist           |
