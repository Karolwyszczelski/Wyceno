# Zasady projektowe

1. **Brief, nie dekoracja.** Interfejs ma porządkować zakres, decyzje i status.
2. **Wyjaśniaj wynik.** Cena i score zawsze pokazują założenia lub uruchomione reguły.
3. **Najpierw następna decyzja.** Dashboard odpowiada, co wymaga reakcji.
4. **Progressive disclosure.** Podstawy są widoczne, zaawansowane reguły rozwijane.
5. **Realne dane ponad karty.** Gęsty panel B2B, spokojny marketing.
6. **Dostępność domyślna.** Klawiatura, fokus i czytelne błędy są częścią komponentu.
7. **Bez fałszywej pewności.** Orientacyjny wynik jest opisany uczciwie.

Zakazane: neonowe gradienty, glassmorphism, identyczna siatka kart, fałszywe wykresy/logotypy/opinie, pływające elementy bez funkcji, gradientowy tekst i domyślny wygląd biblioteki.
